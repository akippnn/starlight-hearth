# Historical slice contracts

No implementation slice is active or frozen. Files in this directory preserve
the contracts that governed historical candidates and attempts. Their embedded
status lines describe their original context, not current delivery state.

Use `docs/status.md` for current state, `docs/roadmap.md` for future outcomes,
and `docs/identifier-migration.md` for VS/HS aliases. A future contract receives
a new collision-free ID only after explicit review and approval.
