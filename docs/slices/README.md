# Slice contracts

`HSN-001-hearth-native-launcher-nucleus.md` is the first Hearth-native track
contract. Its exact commit is recorded externally after freezing; current
delivery state remains in `docs/status.md`.

Other files preserve contracts that governed historical candidates and
attempts. Their embedded status lines describe their original context, not
current delivery state.

Use `docs/status.md` for current state, `docs/roadmap.md` for future outcomes,
and `docs/identifier-migration.md` for VS/HS aliases and the HSN registry.
