## Failed build evidence

GitHub Actions build `88078440686` ran against
`d6920c24a572a460675b14240d91264b8f579f19`. The Hearth contract job passed.
The image build installed the recorded DMS, niri, and Xwayland Satellite RPMs,
copied the Hearth files, and reported the niri configuration valid. It then
failed in `configure-hearth-session.sh` because `/usr/bin/dms version` was
executed by BlueBuild's root-owned script module and DMS exited with
`This program should not be run as root`.

Repair `fb18d9f16c17072c1aa54bb2d97c4f92a499692a` verifies DMS through
`rpm -q dms` instead of starting the user-session program. All 16 contracts,
shell syntax, recipe YAML parsing, and justfile formatting passed for that
repair on the local host and the x86_64 Bazzite host. A successful complete
image build is still required before the repair is treated as integrated.
