## Initial owner boot evidence

The owner rebased the living-room PC to the signed candidate and booted it on
2026-08-22. The deployed OCI reference was
`ghcr.io/akippnn/starlight-hearth@sha256:fa97f83ee9daddf9f3dd11302d3510e750aecec1ed31a2b88981ac791fa2eb01`;
`rpm-ostree status` reported deployment digest
`sha256:786b486a2b6d6279be69aba22ef8b1e1e4d8925f3e962940f79e765b5ea17a06`
and retained the previous signed Bazzite deployment.

Live inspection proved:

- `NAME=hearthOS`, `PRETTY_NAME=hearthOS`, `VARIANT=Hearth`, and
  `VARIANT_ID=hearth`, with Bazzite/Fedora compatibility fields preserved;
- niri `26.04-1.fc44.x86_64`, DMS `1.5.3-1.fc44.x86_64`, and Xwayland
  Satellite `0.8.2-1.fc44.x86_64` installed;
- niri and DMS started on the LG television, and no stale `starlight` stub was
  present.

The boot exposed three candidate-blocking defects:

1. The existing account still targeted `plasma.desktop`, so the owner had to
   run `steamosctl set-default-desktop-session hearth.desktop` manually.
2. KDE's unconstrained `org.kde.xwaylandvideobridge.desktop` autostart entry
   launched in niri as a tiled 3840×2160 black window and covered DMS. Stopping
   that user service restored the visible desktop.
3. niri's physical-DPI automatic scale selected 1× for the 1600×900 mm LG 4K
   television. A live 2× change produced the appropriate logical 1920×1080
   desktop.

The replacement implementation adds a one-time validated Hearth Desktop
selector, restricts Xwayland Video Bridge to KDE, and runs a nonfatal niri
display policy. The policy was exercised against the live niri JSON for
`LG Electronics / LG TV SSCR2`: active 3840×2160 mode, 1600 mm width, resulting
logical 1920×1080 at scale `2.0`. No explicit owner/DMS scale was present.

The source contracts pass **22 tests** on macOS and x86_64 Bazzite, including
large-TV selection, ordinary-display delegation to niri auto, explicit owner
scale precedence, malformed-output degradation, and one-time Desktop
selection. A replacement immutable image has not yet been built or audited.
