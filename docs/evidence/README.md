# Evidence records

Evidence in this directory is retained without relabeling. Passing source,
package, image, or hardware checks prove only the surface and candidate they
name. They do not establish current implementation, audit-readiness, or owner
acceptance.

`HSN-001.md` is the mutable evidence record for the first Hearth-native slice.
Interpret historical records through `docs/status.md` and their original
contracts.
